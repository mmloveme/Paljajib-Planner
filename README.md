# Reserve Planner

개인용예약 플래너입니다. 브라우저에서 바로 열어 월간/주간 캘린더, 일일 노트, 시간대별 예약을 관리할 수 있습니다.

## 포함 기능

- 월간 캘린더 뷰
- 주간 캘린더 뷰
- 날짜별 상세 노트
- 시간대, 이름, 전화번호, 시술 메모가 포함된 예약 리스트
- `localStorage` 기반 저장
- `manifest` + `service worker` 기반 홈 화면 추가/오프라인 지원

## 실행

정적 파일이라 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

보다 안정적인 PWA 동작을 원하면 간단한 정적 서버로 열면 됩니다.
